## 📥 Download & Instalasi

1. Tekan tombol **DOWNLOAD APK** di atas.
2. Download file ZIP dari MediaFire.
3. Ekstrak file ZIP menggunakan pengelola file.
4. Cari file APK di dalam folder hasil ekstrak.
5. Buka APK dan ikuti proses instalasi Android.

> **Catatan:** File unduhan berbentuk ZIP. Ekstrak terlebih dahulu untuk mendapatkan file APK.

## 🔑 Cara Mendapatkan Key

1. Tekan tombol **GET KEY** untuk membuka halaman pengambilan key.
2. Ikuti instruksi yang muncul di halaman tersebut.
3. Selesaikan proses verifikasi atau langkah yang diminta.
4. Setelah key berhasil didapatkan, salin key tersebut.
5. Masukkan key ke aplikasi jika diminta.
